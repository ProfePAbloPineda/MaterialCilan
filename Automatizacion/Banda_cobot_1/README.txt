El HTML usa rutas relativas. Todos los archivos deben quedar en la misma carpeta.

Para cambiar la imagen del proceso: reemplazar 1_proceso.jpg.
Para cambiar la captura de símbolos: reemplazar 2_mapeo.jpg.
Para incorporar el video: copiar el MP4 y nombrarlo video_proceso.mp4.

Los tres archivos de proyecto se enlazan como descarga local. Si sus nombres reales son otros,
se pueden renombrar a los nombres indicados o modificar los atributos href en la sección 2 del HTML.
