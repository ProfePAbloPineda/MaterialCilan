1. Situación de trabajo

Se requiere construir un instrumento electrónico capaz de medir la temperatura ambiente y mostrarla de dos maneras: numéricamente en una pantalla LCD de 16×2 caracteres y mediante una barra de seis LED. El equipo debe disponer de un botón que permita alternar entre el estado activo y el estado apagado lógico. En el nivel de temperatura más alto deberá advertir mediante el parpadeo del último LED.

Desafío: diseñar, montar, programar, probar y explicar un instrumento operativo. El programa final es responsabilidad del estudiante: esta guía proporciona criterios y pruebas parciales, no la solución completa.

2. Aprendizajes esperados

  • Interpretar la salida analógica de un sensor LM35 y convertirla a grados Celsius.
  • Implementar indicadores LED asociados con rangos de temperatura.
  • Configurar una pantalla LCD con adaptador I2C de cuatro conexiones.
  • Administrar un pulsador como interruptor lógico y aplicar antirrebote.
  • Integrar subsistemas y documentar las pruebas realizadas.

6. Fundamento técnico: LM35 y escalamiento

El LM35 entrega una tensión proporcional a la temperatura: 10 mV/°C. Para la conexión básica con referencia ADC de 5 V del Arduino UNO, analogRead(A0) devuelve un valor entero entre 0 y 1023, con 1024 niveles de cuantización.

Relación de cálculo:
Voltaje (V) ≈ lectura ADC × 5,0 / 1024
Temperatura (°C) ≈ voltaje (V) × 100
5,0 V es una aproximación: la precisión depende de la referencia real del ADC y del sensor.
ADC (aprox.)VoltajeTemperatura
410,200 V20,0 °C
610,300 V30,0 °C
920,449 V44,9 °C

Actividad de cálculo: si el conversor entrega 72 cuentas ADC y se supone una referencia de 5,0 V, determine el voltaje y la temperatura aproximada. Justifique cada operación.

7. Desarrollo por etapas

Etapa A: prueba del sensor LM35

  1. Monte solo el LM35 y conecte 5 V, GND y A0.
  2. Realice lecturas por monitor serie e implemente la conversión de ADC a °C.
  3. Registre valores a temperatura ambiente y frente a un calentamiento suave con la mano, sin aplicar llamas ni fuentes de calor peligrosas.

Fragmento parcial de prueba (no es el programa final):

const int PIN_LM35 = A0; void setup() { Serial.begin(9600); } void loop() { int adc = analogRead(PIN_LM35); float voltios = adc * (5.0 / 1024.0); float temperatura = voltios * 100.0; Serial.print("Temperatura (C): "); Serial.println(temperatura, 1); delay(500); // Solo para esta prueba aislada }

Etapa B: prueba de la pantalla LCD con I2C

  1. Conecte solo el LCD con su adaptador I2C: VCC, GND, SDA y SCL.
  2. Instale una biblioteca compatible con el módulo: por ejemplo LiquidCrystal_I2C (verifique la versión utilizada en el laboratorio).
  3. Confirme la dirección I2C, habitualmente 0x27 o 0x3F. Si no funciona, utilice un escáner I2C.
  4. Envíe un mensaje fijo, luego un valor numérico. Actualice únicamente los caracteres que cambian y evite utilizar lcd.clear() continuamente para no producir parpadeo.
// Fragmento ilustrativo para bibliotecas compatibles #include <Wire.h> #include <LiquidCrystal_I2C.h> LiquidCrystal_I2C lcd(0x27, 16, 2); // En setup(): lcd.init(); lcd.backlight(); lcd.setCursor(0, 0); lcd.print("TERMOMETRO LM35"); // Ejemplo de actualizacion localizada: lcd.setCursor(0, 1); lcd.print("Temp: 25.0 C ");

La sintaxis de inicialización puede variar según la biblioteca. Verifique el ejemplo de la biblioteca instalada.

Etapa C: seis LED y tabla de rangos

  1. Monte seis LED, cada uno con su resistencia individual de 330 Ω.
  2. Compruebe manualmente su encendido individual desde D2 a D7.
  3. Diseñe el algoritmo que calcula cuántos LED deben quedar encendidos según la tabla de rangos.
  4. Para la alarma, programe el parpadeo del sexto LED con millis(), sin detener la actualización del sensor.

Etapa D: pulsador de encendido y apagado lógico

  1. Conecte un pulsador entre D8 y GND.
  2. Configure pinMode(8, INPUT_PULLUP).
  3. Detecte un evento de pulsación para cambiar el estado activo/apagado una sola vez por presión.
  4. Incorpore antirrebote y evite que una pulsación sostenida cambie repetidamente el estado.
Importante: el pulsador no corta la alimentación física; alterna estados de funcionamiento por software. Esta distinción debe explicarse en el informe.

Etapa E: integración final

  1. Integre lectura LM35, escalamiento, LCD, LED y pulsador.
  2. Verifique que el sistema no se congele cuando el sexto LED parpadea.
  3. Revise las transiciones de rangos y que el botón responda durante la visualización.
  4. Ordene el cableado y prepare una demostración funcional.

8. Hoja de verificación de pruebas

  • LM35 conectado con polaridad correcta y lectura serie coherente.
  • Escalamiento ADC a grados Celsius implementado y explicado.
  • LCD 16×2 con módulo I2C conectado a A4/A5 y operativo.
  • Seis LED instalados, cada uno con resistencia limitadora.
  • Rangos de temperatura correctamente representados.
  • LED 6 parpadea en condición de alarma.
  • Pulsador cambia entre activo y apagado lógico sin rebotes.
  • El sistema mantiene respuesta mientras actualiza la pantalla.
